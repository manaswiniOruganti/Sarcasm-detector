# Sarcasm-detector# Sarcasm Detection Model

## Overview
This project detects sarcasm in text using machine learning.

## Dataset
- TweetEval Irony Dataset

## Approach
- Text preprocessing
- TF-IDF vectorization
- Logistic Regression classifier

## Results
- Accuracy: ~64%

## Features
- End-to-end pipeline
- Custom prediction function
- Works without GPU

## Example
Input: "Oh great, another Monday morning"  
Output: sarcastic

## How to Run
pip install datasets scikit-learn pandas  
python main.py
